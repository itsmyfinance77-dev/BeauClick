## ۱. طبقه‌بندی داده

هر عنصرِ نمایشی در نمونه‌ها یکی از این چهار است:

| نشان | معنا |
| --- | --- |
| **الف** | داده امروز در پاسخ API هست |
| **ب** | از داده‌های موجود قابل استخراج است (شمارش، گروه‌بندی، اتصال) — بدون فیلدِ تازه |
| **پ** | وابستهٔ سرور — به فیلد یا پارامترِ تازه نیاز دارد |
| **ت** | شکافِ محصول — به قابلیتی نیاز دارد که ساخته نشده؛ در نما ساخته نشد یا جای‌خالیِ صریح دارد |
