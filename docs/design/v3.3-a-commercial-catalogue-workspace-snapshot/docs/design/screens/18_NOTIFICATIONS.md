# اعلان‌ها — /notifications

مسیر: `/notifications`

## وضعیت
طراحی محدود — چیدمان جزئی، نه بازطراحی ساختاری.

## دلیل
این یکی از دو صفحه‌ای است که امروز هم ErrorState واقعی با تلاش دوباره دارد. فهرست + خواندن تکی/همه + ترجیح کانال از قبل کار می‌کند و ساختار درست است.

## تغییرات جزئی
هر آیتم با نشان نوع (رنگ ملایم) و نقطهٔ نخوانده؛ کنش «خواندن همه» بالای فهرست؛ deepLink هر آیتم به مقصد واقعی وصل شود (فیلد در پاسخ هست، مسیریابی آن تصمیم Claude Code است). ترجیح کانال‌های اجباری (mandatory) باید غیرفعال و با برچسب توضیح نشان داده شوند، نه پنهان.
