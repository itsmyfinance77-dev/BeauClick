# باشگاه مشتریان — /loyalty

مسیر: `/loyalty`

## هدف
امتیاز، سطح، پیشرفت تا سطح بعد و تاریخچهٔ امتیاز.

## کاربر و زمینه
نیاز به ورود.

## وابستگی API
loyaltySummary، loyaltyHistory (+ tiers/policy/membership/plans بدون UI امروز)

## فیلدهای واقعی داده
balance، lifetimeEarned، tier، nextTier، pointsToNextTier، percentToNextTier، تاریخچهٔ صفحه‌بندی‌شده با دلیل.

## چیدمان
کارت سطح با نوار پیشرفت بالا؛ فهرست تاریخچه زیر.

## اجزا
LoyaltyCard، ProgressBar (role=progressbar موجود)، EmptyState

## حالت‌ها
بارگذاری اسکلتی؛ خالی تاریخچه: «هنوز امتیازی ثبت نشده»؛ خطا با تلاش دوباره.

## کنش‌ها
مشاهده تاریخچه (فقط نمایشی).

## قواعد واکنش‌گرایی
۳۹۰: کارت تمام‌عرض؛ ۱۲۸۰: کارت + تاریخچه کنار هم.

## قواعد راست‌به‌چپ و فارسی
درصد و امتیاز با ارقام فارسی و tabular-nums.

## دسترس‌پذیری
role=progressbar با aria-valuenow/min/max (امروز موجود، حفظ شود).

## رفتار تعامل
یک توکن شکسته (surface-muted) در این صفحه.

## عناصر آینده/شکاف
طرح‌های عضویت (membership plans) در API هست بدون UI — سطح آزاد طراحی، نه این پاس؛ PRODUCT DECISION REQUIRED که آیا صفحهٔ عضویت جدا لازم است.

## یادداشت پیاده‌سازی
اگر عضویت بعداً طراحی شود، به‌عنوان بخش جدید همین صفحه اضافه شود نه صفحهٔ جدا، تا «باشگاه» یک مقصد واحد بماند.
