# مشخصات دسترس‌پذیری — سطح طراحی

هیچ ادعای تطبیق کامل WCAG اینجا نیست. آنچه زیر آمده مشخصهٔ طراحی است، نه نتیجهٔ تست واقعی با فناوری کمکی — تست غربالگر صفحه هرگز روی این محصول انجام نشده (طبق §۸.۵ سند مرجع) و این سند آن را جایگزین نمی‌کند.

## کیبورد — جلو
تمام کنترل‌ها با Tab قابل‌دسترس، ترتیب تمرکز با ترتیب بصری یکی. `combobox` جست‌وجو باید ArrowDown/Up برای پیمایش پیشنهاد، Enter برای انتخاب، Escape برای بستن داشته باشد — نبودشان امروز نقض واقعی است (§۸.۳ سند مرجع)، نه فقط پیشنهاد طراحی.

## کیبورد — عقب (Shift+Tab)
هرگز به‌صورت واقعی در مرورگر پیموده نشده. مشخصهٔ طراحی: ترتیب تمرکز معکوس باید دقیقاً آینهٔ ترتیب جلو باشد؛ هیچ تله‌ی تمرکز خارج از گفت‌وگو مجاز نیست.

## تمرکز
حلقهٔ دوپیکسلیِ `primary` با فاصلهٔ دو پیکسل، روی همهٔ اجزای کنشی، هرگز `outline:none` بدون جانشین. بازگشت تمرکز بعد از بستن گفت‌وگو به عنصری که آن را باز کرد (رفتار امروز `ConfirmDialog`، حفظ می‌شود).

## معناشناسی خواننده صفحه
`role` صحیح روی هر جزء ترکیبی (combobox/listbox/option، dialog، progressbar، tablist در `/pro/bookings`). `aria-live=polite` روی شمار نتایج جست‌وجو، پیام موفقیت فرم، و بارگذاری فهرست‌ها که امروز فقط در سه‌جا هست.

## Combobox
اصلاح ساختار نامعتبر امروز: `option` نباید فرزند تعاملی (`<button>`) داشته باشد؛ `aria-selected` باید واقعی باشد نه همیشه false؛ `aria-activedescendant` روی گزینهٔ فعال.

## گفت‌وگو
`role=dialog`، `aria-modal`، `aria-labelledby` (امروز موجود) + `aria-describedby` روی متن پیامد (امروز ندارد) + `inert`/`aria-hidden` روی پسِ‌زمینه (امروز ندارد).

## جدول
`caption` + `scope` روی هر سه جدول خام امروز — حفظ می‌شود. جدول جدید (Table استخراج‌شده) همین قرارداد را می‌گیرد.

## فرم
`label`/`htmlFor`، `aria-invalid`، `aria-describedby` برای راهنما و خطا — امروز رعایت شده در Input/Select/Textarea، الگو برای هر ورودی جدید تکرار می‌شود.

## کنتراست
۴٫۵ متن عادی، ۳ متن درشت و اجزای کنشی — همهٔ جفت‌های این سند بررسی‌شده (V3_DESIGN_SYSTEM.md §۱۰). تغییر پالت بدون بازبینی مجدد این نسبت‌ها مجاز نیست.

## هدف لمسی
۴۴ پیکسل کف در موبایل بی‌استثنا؛ اندازه‌های دکمه در سند سیستم طراحی (۵۴/۴۶/۴۲/۴۰) همه پایین‌تر از ۴۴ به هدف لمسیِ بزرگ‌تر از ناحیهٔ بصری می‌رسند (padding نامرئی)، نه با بزرگ‌کردن ظاهر دکمه.

## پیمایش پرش (Skip Navigation)
لینک پرش موجود، مخفی تا فوکوس — حفظ می‌شود بدون تغییر.
