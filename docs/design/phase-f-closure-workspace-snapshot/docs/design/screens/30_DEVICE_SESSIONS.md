# دستگاه‌ها و نشست‌ها — /account/devices

مسیر: `/account/devices` (فاز E، UI REQUIRED — پیش‌تر غیرقابلِ‌ساخت چون `current` همیشه false بود؛ حالا واقعی است، QA-20)

## هدف
دیدنِ دستگاه‌های واردشده به حساب و خروجِ یکی یا همهٔ دستگاه‌های دیگر، بدون خطرِ خروجِ ناخواسته از دستگاهِ فعلی.

## کاربر و زمینه
نیاز به ورود. فهرست همیشه محدود به دستگاه‌های خودِ کاربر.

## وابستگی API
GET /v1/auth/sessions؛ DELETE /v1/auth/sessions/:id؛ POST /v1/auth/logout-all-devices.

## فیلدهای واقعی داده
id، deviceLabel (لاتین‌فقط، از هدرِ `x-device-label`)، userAgent، createdAt (زمانِ ورودِ همین دستگاه، نه توکنِ فعلی)، lastUsedAt، revoked، current (بولی، واقعی).

## چیدمان
فهرستِ ردیف‌ها، جدیدترین/دستگاهِ فعلی اول. ردیفِ دستگاهِ فعلی با نشانِ متمایز («این دستگاه») و بدون دکمهٔ خروج (یا دکمهٔ خروج غیرفعال با توضیح) — دکمهٔ خروجِ خودِ دستگاه با «خروج از حساب» معمولی یکی است، نه این فهرست. زیرِ فهرست، دکمهٔ ثانویه: «خروج از همهٔ دستگاه‌های دیگر».

## اجزا
List/Table ردیفی، Badge («این دستگاه»)، Button (خروجِ تکی، خروجِ همگی)، ConfirmDialog (خروجِ همگی)، EmptyState.

## حالت‌ها
بارگذاریِ اسکلتی؛ خالی — عملاً رخ نمی‌دهد چون دستگاهِ فعلی همیشه در فهرست است، اما اگر فهرست فقط یک ردیف داشت دکمهٔ «خروج از همهٔ دستگاه‌های دیگر» غیرفعال می‌شود نه پنهان؛ خطا با تلاشِ دوباره؛ **نشستِ کهنه**: وقتی `current` روی هیچ ردیفی true نیست (توکنِ صادرشده پیش از این تغییر) — به‌جای فرض‌کردنِ یک ردیف، هیچ ردیفی نشانِ «این دستگاه» نمی‌گیرد و متنِ توضیحی («این‌که کدام دستگاه شماست هنوز مشخص نشده؛ با ورودِ بعدی مشخص می‌شود») بالای فهرست ظاهر می‌شود.

## کنش‌ها
خروجِ یک دستگاه → تأیید کوتاه (نه ConfirmDialogِ کامل، چون بازگشت‌پذیر است: کاربر دوباره وارد می‌شود) → حذفِ فوریِ ردیف؛ خروجِ همهٔ دستگاه‌های دیگر → ConfirmDialog با متنِ «شما از حساب خارج نمی‌شوید» صریح → همهٔ ردیف‌های غیر-current ناپدید می‌شوند.

## قواعد واکنش‌گرایی
۳۹۰: هر ردیف کارتِ مستقل با دکمهٔ خروج زیرِ اطلاعات؛ ۱۲۸۰: ردیفِ افقی با دکمه در انتها.

## قواعد راست‌به‌چپ و فارسی
`createdAt`/`lastUsedAt` به‌صورتِ نسبی («۳ هفته پیش») با اعدادِ فارسی؛ `deviceLabel` و `userAgent` لاتین می‌مانند (`direction: ltr` در یک span مجزا) چون قابلِ‌ترجمه نیستند — نمایشِ خامِ رشتهٔ user-agent باید کوتاه‌شود به یک برچسبِ خوانا (نه رشتهٔ کاملِ مرورگر)، این یک نگاشتِ فرانت است نه فیلدِ جدیدِ API.

## دسترس‌پذیری
هر ردیف به‌عنوانِ گروهی با برچسبِ «دستگاه، [برچسب]، [زمانِ آخرین استفاده]»؛ دکمهٔ خروجِ دستگاهِ فعلی اگر غیرفعال است `aria-disabled` + توضیحِ متنی، نه فقط رنگِ کم‌رنگ.

## رفتار تعامل
هر ردیفی می‌تواند به‌طورِ معتبر `current: false` باشد — این خطا نیست؛ رابط کاربری هرگز فرض نمی‌کند دقیقاً یک ردیف باید نشان‌دار باشد.

## عناصر آینده/شکاف
برچسبِ فارسیِ دستگاه (نمایشِ Latin `deviceLabel` به‌صورتِ متنِ فارسیِ خوانا مثلِ «آیفون») — نگاشتِ فرانت‌محورِ ساده، نه شکاف. مکان‌یابیِ جغرافیایی یا IP دستگاه — در پاسخ نیست و نباید اختراع شود.

## یادداشت پیاده‌سازی
`GET /sessions` یک ردیف به‌ازایِ هر دستگاه می‌دهد نه هر چرخشِ توکن (رفعِ اشکالِ زیرساختی هم‌زمان با این فاز)؛ `createdAt` اکنون زمانِ واقعیِ ورودِ دستگاه است، نه زمانِ آخرین رفرش.
