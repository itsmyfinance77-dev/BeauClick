# زمان‌های آزاد — /pro/availability

مسیر: `/pro/availability`

## هدف
ساخت و مدیریت زمان‌های آزاد، تکی و گروهی.

## کاربر و زمینه
نیاز به نقش bc_provider.

## وابستگی API
listMySlots، createSlot، bulkGenerateSlots، deleteSlot، listMyServices

## فیلدهای واقعی داده
slot id، serviceId، startAt، endAt، status (open/held/booked).

## چیدمان
SegmentedControl برای بازهٔ زمانی (هفته/ماه)؛ شبکهٔ هفتگی (ستون روز × سطر ساعت)؛ فرم ساخت گروهی جدا.

## اجزا
WeekGrid، SegmentedControl، Button

## حالت‌ها
بارگذاری اسکلتی شبکه؛ خالی: روز بدون زمان با سطح خاکستری روشن نه خالیِ سفید؛ خطا با تلاش دوباره.

## کنش‌ها
کلیک/کشیدن روی خانهٔ خالی → ساخت زمان؛ حذف زمان موجود؛ ساخت گروهی با الگوی هفتگی.

## قواعد واکنش‌گرایی
۳۹۰: نمای یک‌روزه با پیمایش افقی روز به روز؛ ۷۶۸: سه‌روزه؛ ۱۲۸۰: هفت‌روزه کامل.

## قواعد راست‌به‌چپ و فارسی
روزهای هفته راست‌چین (شنبه راست‌ترین)؛ ساعت‌ها ستون LTR.

## دسترس‌پذیری
کنترل native <input type=date/time> نگه داشته می‌شود (بازسازی تقویم جلالی سفارشی هزینهٔ بزرگ با سود کم است) — اما باید در چیدمان محلی‌سازی شود تا حداقل برچسب و کنتراست فارسی رعایت شود.

## رفتار تعامل
ساخت گروهی امروز بی‌حافظه است (الگوی هفتگی ماندگار برای ویرایش و تمدید وجود ندارد) — BACKEND GAP وابسته به سرور.

## عناصر آینده/شکاف
جابه‌جایی رزرو با کشیدن روی شبکه — عمداً طراحی نشد، چون قواعد جابه‌جایی در سرور است و باید از همان مسیر تأییدشدهٔ rescheduleBooking عبور کند.

## یادداشت پیاده‌سازی
این صفحه هفت ورودی بومی date/time گرگوری دارد که با محصول فارسی هم‌خوان نیست — بدون تصمیم Jalali picker (که این سند توصیه می‌کند نساخته شود)، حداقل باید تقویم مرورگر فارسی فعال باشد.
