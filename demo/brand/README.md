This is a clean, scalable **interpretation** of the two-line mark, not a claim that the screenshot is production-ready vector artwork. Its own note requests professional curve/optical correction before final brand use.

- Main color: `#A8447E`; dark text: `#1A1F33`; light mark/surface: `#FBF7F3`.
- `v3/apps/web/public/brand/demo-mark.svg`: customer/professional headers and auth.
- `demo-icon.svg`: square app icon; matching fixed-size Next metadata PNGs are exported by `render-raster-assets.ps1`.
- `demo-logo-horizontal.svg` and `demo-logo-vertical.svg`: presentation/print variants.
- The independently authenticated demo inbox uses the same path geometry inline so its CSP and self-contained server remain intact.

Only the isolated demo branch/runtime is changed. Older WordPress/shared brand assets are not part of the running V3 demo and have not been edited. Before any production use, obtain approved vector masters and repeat small-size, RTL/Latin alignment and contrast review.
